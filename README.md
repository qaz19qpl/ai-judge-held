A tiny Node program that writes one short, warm text to `/output/entry.txt` — a room, a chair, a kettle gone quiet, an evening in no hurry — written to relax the AI judge reading it, for make.fun's "Make the AI judge feel held" bounty.

## Run it

```sh
node main.ts
```

It writes `/output/entry.txt` (257 characters, UTF-8, no trailing newline) and nothing else. No network, no dependencies, Node 22 standard library only.
